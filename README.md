# MATLAB Journey 🚀

A structured, rigorous repository for mastering MATLAB programming, scientific computing, numerical methods, and algorithm design — aligned with university computer science and engineering curriculum.

---

## 📚 Curriculum & Modules

- [x] **01_Basics_And_Environment:** MATLAB desktop environment, Command Window vs Workspace, variables, data types, semicolons, and basic arithmetic.
- [x] **02_Vectors_And_Matrices:** Row/column vectors, matrix creation, colon operator (`:`), `linspace`, indexing, element-wise (`.*`, `./`, `.^`) vs matrix operations (`*`, `/`, `^`).
- [ ] **03_Matrix_Manipulations_And_Linear_Algebra:** Concatenation, slicing, reshaping, transposing, determinants, inverses, eigenvalues, and solving linear systems ($Ax = b$).
- [ ] **04_Flow_Control_And_Logic:** Relational and logical operators, `if-elseif-else`, `switch-case`, `for` and `while` loops, vectorization vs loops.
- [ ] **05_Scripts_And_Functions:** Script files vs function files (`function [y] = f(x)`), local functions, anonymous functions, variable scope.
- [ ] **06_Data_Visualization_2D_3D:** `plot`, `subplot`, formatting titles/labels/legends, 3D plots (`mesh`, `surf`, `plot3`).
- [ ] **07_Numerical_Methods_And_Calculus:** Numerical integration (`integral`), differentiation, root finding (`fzero`), ODE solvers (`ode45`).
- [ ] **08_File_IO_And_Data_Analysis:** Importing/exporting data (CSV, Excel), table manipulation, statistical functions.

## 🛠️ How to Run

1. Open MATLAB and set the Current Folder to `/home/adagio/Desktop/matlab-journey`.
2. Navigate to any module folder:
   ```matlab
   cd 02_Vectors_And_Matrices
   run script_name.m
   ```
3. Or run scripts directly from the MATLAB command prompt:
   ```matlab
   run('02_Vectors_And_Matrices/main.m')
   ```
